# CobaltDrift

Transfers sensitive data between remote servers and devices using end-to-end encryption and secure authentication protocols.

With CobaltDrift, you get a lightweight tool that stays out of your way.

**What you get**

- Transfers sensitive data between remote
- servers and devices using end-to-end
- encryption and secure authentication protocols

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/CobaltDrift.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
